# Meu Financeiro V1

Aplicativo pessoal simples para:
- Pessoa Física: entradas, saídas, saldo e histórico.
- CNPJ: entradas, saídas, saldo e histórico.
- Pagamentos: a pagar, a receber, vencidos e baixa.
- Orçamentos: cliente, WhatsApp, itens, imagens, total, impressão/PDF e compartilhamento.

## Como abrir no computador
1. Extraia a pasta.
2. Dê dois cliques em `index.html`.
3. O aplicativo abre no navegador.

## Dados
Os dados são salvos no `localStorage` do navegador. Portanto:
- ficam neste navegador/dispositivo;
- limpar os dados do navegador pode apagar os registros;
- esta V1 não sincroniza automaticamente computador e celular.

## PDF
No orçamento salvo, clique em **PDF / Imprimir**.
Na tela de impressão do navegador, escolha **Salvar como PDF**.

## WhatsApp
O botão **WhatsApp** abre a conversa com a mensagem do orçamento.
O botão **Compartilhar** usa o compartilhamento nativo do celular quando disponível.

Observação: nesta primeira versão, o PDF é salvo pelo navegador. Para anexar o arquivo no WhatsApp, selecione o PDF salvo no próprio WhatsApp/compartilhamento do aparelho.

## Importante
Esta versão foi propositalmente mantida pequena, sem IA, sem backend, sem login e sem integração com HOVEI.
